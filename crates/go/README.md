# Secure Tunnel Native Go SDK

`task-00000029` packages the supported Go SDK as a native cgo module over the
manual Secure Tunnel C ABI.

The supported Go module lives under:

```text
crates/go
```

Its module path is:

```text
github.com/asim-playground/secure-tunnel/crates/go
```

The tracked C header is generated by `cbindgen`:

```text
crates/go/binding.h
```

Useful tasks:

```bash
mise run sdk:go:check-package
mise run sdk:go:smoke-package
mise run sdk:go:smoke-release
mise run sdk:go
```

The release dry-run packages the module root, `binding.h`, and a host native
`secure_tunnel_ffi` dynamic library under `native/<goos>-<goarch>/`. Consumers
should import the package as `securetunnel` and use the hand-written Go API
rather than calling C symbols directly.

The dry-run artifact includes `native.json` with the ABI version, supported
platform entries, library paths, SHA-256 checksums, and byte sizes. The external
release smoke unpacks that artifact into a temporary directory, creates a fresh
consumer module, points `LD_LIBRARY_PATH` or `DYLD_LIBRARY_PATH` at the bundled
native library directory, and runs a fixture-backed session smoke outside the
monorepo layout.
