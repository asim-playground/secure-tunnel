# Secure Tunnel Native Go SDK

`task-00000029` packages the supported Go SDK as a native cgo module over the
manual Secure Tunnel C ABI.

The supported Go package lives under:

```text
crates/go/go
```

The tracked C header is generated by `cbindgen`:

```text
crates/go/binding.h
```

Useful tasks:

```bash
mise run sdk:go:check-package
mise run sdk:go:smoke-package
mise run sdk:go
```

The C ABI exposes coarse SDK operations only: client creation, connect,
connect/security reports, account auth, request/response, close, and explicit
free functions. Go code should use the hand-written package in `go/` rather
than calling C symbols directly.
